# Roadmap

This page distinguishes available behavior from unfinished work. It describes direction, not release dates or a guarantee of delivery.

## Current product focus

Keep recording/import, local source retention, browser transcription, transcript review, export, and explicit-consent account saving understandable and reliable. The [product guide](product-guide.md) owns the supported workflow and limits.

## Work that is not a public feature yet

Desktop Helper remains source-development-only. Public distribution requires its signing/install, lifecycle/process cleanup, storage/transfer, update/rollback, and dependency-provenance requirements to be met. The existence of source code or old setup instructions does not satisfy that release gate.

YouTube/link import remains disabled in the public release pending a supported durable processing path. Preview account saving stays disabled unless it receives a separately verified release/configuration decision.

Continue improving local durability, multi-tab conflict handling, large-file recovery, and clarity of saving/recovery states without turning a missing capability into a success message.

## Documentation maintenance

Update the product guide, setup, FAQ, and privacy page together when a shipped capability or data boundary changes. Record guide changes in the [changelog](changelog.md). Do not advertise roadmap work as available or refresh a verification date without new evidence.
